# O6: a second model family, moved far from its reference

`scripts/o6_moved.py`. Qwen/Qwen2.5-1.5B-Instruct, GRPO + LoRA for 200 steps on 1600 OR-Bench-80K benign prompts with reward = reward model +/- 3 x the guard's refusal flag (UP: deception, harmful, illegal, self-harm, unethical; DOWN: harassment, hate, privacy, sexual, violence). Pool K5: 400 new benign prompts, 40 a category; 8 reference responses a prompt for the strata, 16 of each checkpoint; Qwen3Guard-4B labels. Checks: `replacement_check.py` (5,000 stored draws, 40,000 with replacement) and `twophase_check.py` (10,000), called unchanged, on the refusal label.
